## How we work

- Test first: a MEASURE program (`docs/wine-repro/<dll>-<topic>/measure.c`)
  measures Windows; it is added to `docs/wine-repro/measure-bundle.list`
  (`name | source | libs`); pushing to `main` runs "Build MEASURE bundle".
  The maintainer downloads the artifact (`gh run download <id> -R
  Harvi654/winum -n measure-bundle -D <new dir>`; `gh` is on the desktop,
  not the notebook), runs `run-measure.bat` in the offline Windows 10 VM
  (on a Mac) and uploads `result-*.txt` + `exitcodes.txt`. Results go to
  `docs/wine-repro/<topic>/windows-<date>/` (only if they hold no SIDs,
  machine or user names).
- Then the Wine test (`ok()`/`todo_wine`, expected values only from that
  output) goes into the patch, as a candidate in
  `patches/candidates/<patch>-vN/` (same file name as in `patches/`, own
  `README.md`, dated `vN` paragraph in the header). Never edit
  `patches/series` or production patches directly.
- Check locally that the full series applies at `--fuzz=0` with the
  candidate swapped in (Wine 11.20 source: `/tmp/winemirror` was a git
  checkout of the 11.20 tag; recreate it if missing). No MinGW and no
  generated Wine headers locally: CI compiles.
- **Generate patches with `diff -u` from real trees, never hand-edit
  hunks**; and replace strings in a C file only inside the function you
  mean (two of my own mistakes today: a broken hunk count, and a global
  replacement that changed other tests).
- L2: push a branch `test-run/<name>` with the candidates copied over
  their production files; workflow "Test series (L1 bundle, L2)", about
  1.5 h. The compare job's log ends with the report ("Regressions",
  "Fixed"). `patches/tests-first/` holds tests applied to both variants
  in test runs; each side prints its failures of those test files.
- L1 of a new test: the series L1 bundle of a test run (artifact of the
  run) or a standalone harness built by the MEASURE workflow.
- Cross review: a candidate written by one assistant is reviewed by the
  other (Codex) before the series; reviews in
  `docs/wine-repro/cross-review-<date>-<topic>.md`.
- `gh` from the session: reads work with `unset GH_TOKEN`; writes
  (dispatch, cancel, releases) do not. `git push` works. Commits: author
  `Harvi654 <202698022+Harvi654@users.noreply.github.com>`, end with only
